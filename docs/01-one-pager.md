# ors — 让优化模型可解释

> **一句话**：开源求解器只告诉你 `infeasible`；ors 告诉你**为什么**、**改哪里**、**凭什么**。

状态：pre-alpha（2026-10）｜工作名，发布前需查重｜Apache-2.0

---

## 1. 问题

运筹学从业者的时间，大部分不是花在"求解"，而是花在"模型为什么不对"上：

- 模型跑出 `infeasible`，面对几万条约束，不知道哪几条互相矛盾。
- 想放松约束让模型可行，不知道改哪条、改多少，代价最小。
- 求解器说"最优"，但你不确定它是不是算错了。
- 改了一个参数，解完全变了，不知道是哪条约束在起作用。

现有工具的能力分布：

| 能力 | Gurobi / CPLEX | HiGHS | Pyomo | ors |
|---|---|---|---|---|
| 返回状态码 | ✅ | ✅ | ✅ | ✅ |
| IIS（冲突约束集） | ✅ | ❌ | ✅ 但需商业后端 | ✅ |
| 可行性松弛建议 | ✅ | ❌ | ❌ | ✅ |
| 可独立验证的证书 | 部分 | ❌ | ❌ | ✅ |
| 自然语言解释 | ❌ | ❌ | ❌ | ✅ |
| 开源 | ❌ | ✅ | ✅ | ✅ |
| 价格 | 昂贵 | 免费 | 免费 | 免费 + 商业 |

**空档很清楚：能力存在，但碎片化、绑定商业后端、没有 Python 原生的完整体验。**

---

## 2. 为什么是现在

1. **开源求解器已经够好**。HiGHS 让"不买 Gurobi"成为可行选择，但它的可观测性几乎为零。用的人越多，调试痛点被放大得越快。
2. **LLM 让"翻译"成为可能**。把数学冲突（一组约束 + 对偶射线）翻译成业务语言（"冷库容量和周二夜班冲突"），三年前做不到。
3. **Python OR 生态成熟**。Pyomo、JuMP、CVXPY 解决了"建模"，但没人解决"调试"。这是最后一块拼图。
4. **AI 让单人开发成为可能**。诊断层的算法都是公开的、模式化的，正好落在 AI 最擅长的区间。

## 3. 产品：三层能力

### L1 诊断（0~6 个月）

- **IIS**：最小冲突约束集，带原始表达式和名字。
- **可行性松弛**：最少改哪几处、改多少，总代价最小。
- **模型体检**：大系数 / big-M / 重复约束 / 自由变量 / 退化 / 缩放报告。
- **diff + 增量重解**：改了什么，解为什么变了。

### L2 证书（3~12 个月）

- LP 不可行：Farkas 对偶射线，独立验证。
- LP 无界：无界射线。
- LP 最优：原始-对偶可行性残差。
- MILP：不承诺短证书，给"搜索证明 + 松弛 IIS + 冲突分析"。

### L3 解释（6~12 个月）

- 把 IIS + 模型元数据交给 LLM，生成业务语言报告。
- 支持本地模型（隐私）和云端模型。
- 明确标注"AI 生成，需人工复核"。

| 用户 | 场景 | 付费意愿 |
|---|---|---|
| OR 分析师 / 数据科学家 | 排产、供应链、定价模型调试 | 中 |

| 企业决策优化团队 | 生产环境模型可观测性 | 高 |
| 求解器开发者 | 调试 presolve / 割平面 | 中 |

**先服务第一类，用第三类变现。**

---

## 5. 差异化

不是"更快的求解器"，而是"求解器的可观测性层"：

- **互补而非竞争**：后端可以接 HiGHS、SCIP，未来接自研内核。
- **可验证**：每个结论都有证书，不靠"相信我"。
- **Python 原生**：`m.diagnose()`，不是命令行工具 + 日志文件。
- **解释优先**：输出是给人看的，不是给矩阵看的。

## 7. 成功指标

- **90 天**：10 个真实用户、3 个可复现案例、IIS 中位耗时 < 10× 单次 LP。
- **12 个月**：被 Pyomo/JuMP 生态引用，1000 月活，至少 1 个企业用户。
- **3 年**：成为开源 OR 的默认诊断层。

## 8. 商业模式

- **核心 Apache-2.0 开源**：诊断、证书、Python API。
- **商业版**：团队协作、云端大规模诊断、SLA、私有部署、审计报告。
- **咨询/培训**：模型诊断服务，反哺开源。

---

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 用户只关心速度，不关心解释 | 先用 3 个案例证明"省下的时间" |
| MILP 诊断太难 | 先 LP，再 MILP；明确能力边界 |
| 商业求解器免费版覆盖 | 绑定开源生态，做它们不做的 |
| 单人不可持续 | 控制范围，90 天一个里程碑，尽早社区化 |
| IIS 结果不可读 | 解释层 + 按业务重要性排序 |
